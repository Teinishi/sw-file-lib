# @sw-file-lib/geometry

TypeScript libraries for reading, writing **Stormworks** files.

This package includes geometry construction, mesh generation, and surface operations such as culling. For other packages, see [GitHub Repository](https://github.com/Teinishi/sw-file-lib).

[Get Started](https://teinishi.github.io/sw-file-lib/guide/generating-geometry.html)
