# @sw-file-lib/three

TypeScript libraries for reading, writing **Stormworks** files.

This package includes three.js helpers including coordinate conversion, mesh creation, and materials. For other packages, see [GitHub Repository](https://github.com/Teinishi/sw-file-lib).

[Get Started](https://teinishi.github.io/sw-file-lib/guide/threejs-integration.html)
