# @sw-file-lib/core

TypeScript libraries for reading, writing **Stormworks** files.

This package includes reading/writing binary files and some utilities. For other packages, see [GitHub Repository](https://github.com/Teinishi/sw-file-lib).

[Get Started](https://teinishi.github.io/sw-file-lib/guide/read-write-binary.html)

## Exports

| Exports                   | Description                                        |
| ------------------------- | -------------------------------------------------- |
| `@sw-file-lib/core`       | Binary file reading and writing                    |
| `@sw-file-lib/core/math`  | Vectors, matrices, orientation, and math utilities |
| `@sw-file-lib/core/color` | Color types and parse utility                      |
