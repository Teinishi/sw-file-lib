# @sw-file-lib/xml

TypeScript libraries for reading, writing **Stormworks** files.

This package includes parser, serializer, and typed schemas for Stormworks XML files. For other packages, see [GitHub Repository](https://github.com/Teinishi/sw-file-lib).

[Get Started](https://teinishi.github.io/sw-file-lib/guide/read-write-xml.html)
